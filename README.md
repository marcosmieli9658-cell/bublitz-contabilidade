# Bublitz Contabilidade

Site institucional em React/Vite, publicado no GitHub Pages. O scaffold do Sites/Vinext é preservado para desenvolvimento local e uma construção estática dedicada gera a versão pública.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run build
npm run lint
```

O conteúdo institucional foi preparado a partir dos materiais fornecidos pela empresa. Confirme informações de contato, serviços e CNPJ antes de tratar a prévia como versão oficial.
